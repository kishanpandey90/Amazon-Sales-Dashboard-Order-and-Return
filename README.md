# Amazon Sales Dashboard

An interactive e-commerce sales dashboard built using Microsoft Power BI.

## Project Overview
This project analyzes sales, orders, customers, profit, and returns through interactive visualizations.

## Key Metrics
- Total Orders: 6K
- Total Customers: 4K
- Total Sales: 471.55K
- Total Profit: 138.81K
- Return Rate: 8.28%

## Dashboard Features
- KPI cards for business performance
- Returned vs Non-Returned donut chart
- Monthly Sales Trend (2023–2025)
- Category and regional analysis
- Interactive date and category slicers

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
